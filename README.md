Uber Mobile App — Manual Testing Portfolio Project

Overview

Independent manual-QA portfolio project for the Uber Rider mobile app. It demonstrates test planning, detailed test-case design, smoke/regression testing, mobile testing, and bug reporting.

This is not an official Uber repository. Demo defects are examples, not claims about production bugs.

Scope

Account access; location permissions; pickup/destination; ride options and pricing; ride request/cancellation; driver/vehicle information; trip state; payment/receipt; ratings/tips; safety tools; profile/settings; network and app-state recovery.

Out of Scope

Driver internal workflows, backend/database access, unauthorized security testing, real emergency-service testing, payment abuse, and unavailable regional features.

Test Types

Functional • Positive • Negative • Smoke • Regression • Usability • Compatibility • Recovery • Exploratory

Workflow

Review TEST_PLAN.md.

Execute applicable test cases on an authorized account/device.

Record Pass, Fail, Blocked, or Not Run.

Create a bug report for failures.

Run smoke/regression checklists.

Update the execution report.

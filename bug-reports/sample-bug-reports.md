# Sample Bug Reports


## BUG-001 — Updated pickup not reflected on confirmation screen
**Severity:** Major | **Priority:** High | **Type:** Demo  
**Environment:** Android / example build / Wi-Fi  
**Steps:** 
1. Enter destination. 
2. Change pickup. 
3. Confirm pickup. 
4. Continue.  
**Expected:** New pickup appears consistently.  
**Actual (demo):** Previous pickup remains displayed.  
**Reproducibility (demo):** 3/3

## BUG-002 — Destination search stays loading after network returns
**Severity:** Major | **Priority:** Medium | **Type:** Demo  
**Steps:** 1. Open search. 2. Disable network. 3. Search. 4. Restore network. 5. Retry.  
**Expected:** App reconnects or provides retry and results.  
**Actual (demo):** Loading remains indefinitely.

## BUG-003 — Long destination text overlaps action
**Severity:** Minor | **Priority:** Low | **Type:** Demo  
**Steps:** 1. Increase font size. 2. Select long location name. 3. Review confirmation.  
**Expected:** Text wraps/truncates without covering controls.  
**Actual (demo):** Text overlaps action control.
